## What Was Built

### Task 1 — realtime_nav_core.py

- Added `from config import BEV_OBSTACLE_PENALTY_WEIGHT` at module top
- Added `self.obstacle_zones: list = []` to `BEVPathExtractor.__init__`
- Changed `process()` signature to `process(self, bev_mask_255, obstacle_zones_m=None)`
- Added `self.obstacle_zones = list(obstacle_zones_m) if obstacle_zones_m else []` at start of `process()`
- Added `_obstacle_penalty(self, path_pts_m)` method: sums fraction of path points within each obstacle zone's radius; returns 0.0 when `self.obstacle_zones` is empty
- In `_score_candidates()`: appended `BEV_OBSTACLE_PENALTY_WEIGHT * j_obstacle` to `c.cost` when `len(cands) >= 2` (avoids penalizing the only viable path)

### Task 2 — live_heading_demo.py

- Added `from bev_obstacle import project_foot_to_bev, detection_to_metric, ObstacleEMAGrid`
- Added `BEV_OBSTACLE_RADIUS_PX, BEV_HARD_BLOCK_DIST_M` to config imports
- Instantiated `obstacle_ema = ObstacleEMAGrid(bev_h=BEV_SIZE[1], bev_w=BEV_SIZE[0])` once before the main loop
- On compute frames with new detections: project foot BEV points and call `obstacle_ema.update(foot_bev_pts)`
- On skip-detection frames: call `obstacle_ema.update([])` to allow EMA decay
- Before `path_extractor.process()`: hard-block loop paints `cv2.circle(..., 0, -1)` for detections with `distance_m < BEV_HARD_BLOCK_DIST_M`; builds `obstacle_zones` list via `detection_to_metric`
- Changed process call to `path_extractor.process(bev_sidewalk, obstacle_zones_m=obstacle_zones if obstacle_zones else None)`

### Task 2 — tests/test_bev_obstacle.py (OBS-05, OBS-06, OBS-08, OBS-09)

- **OBS-05** (`test_obstacle_penalty_prefers_clear_path`): tests `_obstacle_penalty` directly — asserts 0.0 for empty zones, nonzero for obstacle on path, 0.0 for obstacle far off to the side
- **OBS-06** (`test_hard_block_masks_bev`): applies `cv2.circle` to a white mask using `project_foot_to_bev` on a close detection; asserts center pixel == 0
- **OBS-08** (`test_no_penalty_when_no_obstacles`): asserts `_obstacle_penalty` returns 0.0 for empty list; verifies `process(mask, obstacle_zones_m=None)` and `process(mask, obstacle_zones_m=[])` both return a valid `PathPlanResult`
- **OBS-09** (`test_integration_full_pipeline`): full end-to-end — instantiates `BEVPathExtractor` + `ObstacleEMAGrid`, projects detection, updates EMA, builds `obstacle_zones`, calls `process(obstacle_zones_m=obstacle_zones)`, asserts `PathPlanResult` attributes accessible
