### Task 2: bev_obstacle.py (new module, 140 lines)

Three independently importable exports:

**`project_foot_to_bev(det, H, bev_h=500, bev_w=600) -> (float, float)`**
- Takes detection dict with "bbox": (x1, y1, x2, y2)
- Computes foot = bbox bottom-center, applies `cv2.perspectiveTransform(foot, H)`
- Clamps output to [0, bev_w-1] x [0, bev_h-1] — never raises on out-of-bounds

**`detection_to_metric(det, H, bev_mask_shape) -> (forward_m, lateral_m)`**
- Calls `project_foot_to_bev`, then converts pixels to meters
- `forward_m = (bev_h-1 - by) / (bev_h-1) * NAV_BEV_FORWARD_M`, clamped >= 0.3
- `lateral_m = (bx / (bev_w-1) - 0.5) * NAV_BEV_LATERAL_M` (signed, left negative)

**`ObstacleEMAGrid(bev_h, bev_w, alpha, footprint_radius_px)`**
- `.update(foot_bev_pts)` — draws cv2.circle at each point on new_frame, then EMA
- `.reset()` — zeros the grid
- Decays from 1.0 → <0.01 in 10 frames at alpha=0.5 (0.5^10 ≈ 0.001)
