## Decisions Made

- **Scan raw BEV mask pixels, not corridor abstraction, for support detection:** `corridor_from_mask()` merges adjacent pixel runs into a single widest run per row. This hides asymmetric turn openings (e.g., a left opening cols 20-80 merges with center corridor cols 80-140). Direct pixel counting on each side of ego correctly detects the asymmetry.

- **Asymmetric pixel count as support metric:** A row has commanded-side support when the number of drivable pixels on the commanded side exceeds the opposite side by a minimum asymmetry threshold. This cleanly distinguishes a narrow centered corridor (symmetric, no turn) from one with a side opening (asymmetric, turn supported).

- **Widen decision band from 1.8-3.2m to 2.0-7.0m:** Turn openings in BEV are visible further ahead than the original narrow band. The 220px test fixtures place openings at 4.5-8.2m forward. Real-world intersections would also show turn support well ahead of the scooter.

- **Cubic Hermite smoothstep path:** `y(t) = apex_lat * (3t^2 - 2t^3)` provides zero tangent at ego (starts straight), reaches apex lateral, then linearly blends to exit. This avoids the overshoot that polynomial fitting produces and gives controller-friendly curvature.

- **Dual-gate approval architecture:** Target gate checks `support_score >= acquire_support_min`. Path gate checks `containment >= path_containment_min` AND `near_containment >= near_containment_min`. Both gates must pass for active result. This prevents approving a turn where support exists but the path clips the corridor boundary.

## Deviations from Plan

## Issues Encountered

- Initial support extraction used corridor left/right boundaries, which merge adjacent runs and cannot distinguish asymmetric openings. Fixed by switching to raw BEV mask pixel scan.
- Initial path fitting used quadratic polynomial through 3 control points, causing severe overshoot (lateral=-4.37m vs target=-2.04m). Fixed by switching to Hermite smoothstep interpolation.
- Default decision band (1.8-3.2m) was too narrow for test fixtures where openings appear at 4.5-8.2m. Widened to 2.0-7.0m which also better matches real BEV geometry.
