```python
class TemporalMaskSmoother:
    def __init__(self, alpha=MASK_SMOOTH_ALPHA, consistency_thresh=MASK_SMOOTH_CONSISTENCY_THRESH):
        """
        alpha: EMA weight for current frame (higher = more responsive to changes).
               MUST be >= 0.25 to satisfy SEG-03 (obstacles visible within 3 frames).
        consistency_thresh: IoU below this triggers conservative blending (alpha * 0.25).
        """
    def smooth(self, mask_255: np.ndarray, return_iou: bool = False):
        """Returns smoothed uint8 mask (0/255), or (mask, iou) if return_iou=True."""
    @staticmethod
    def _iou(a: np.ndarray, b: np.ndarray) -> float:
        """IoU between float masks. Handles empty masks (returns 0.0 when union=0)."""
```

  <action>
    Create scripts/tune_smoother.py.

    The script must:
    1. Accept --video CLI argument (default: test_video_mar3_1_h264.mp4)
    2. Accept --max-frames CLI argument (default: 500)
    3. Load all raw masks from the video using the current MODEL_DIR (already updated in config.py by Plan 01-01):
       - Instantiate FastRoadDetector with Config(model_dir=config.MODEL_DIR, enable_logging=False)
       - Read up to --max-frames frames, collect raw masks into a list (do NOT apply smoother yet)
       - This single pass loads masks once; the sweep then replays them without re-running GPU inference
    4. Define sweep grid:
       - alphas = [0.25, 0.30, 0.35, 0.40, 0.45, 0.55, 0.65]
       - thresholds = [0.20, 0.25, 0.30, 0.40, 0.50]
    5. For each (alpha, thresh) combination:
       a. Create fresh TemporalMaskSmoother(alpha=alpha, consistency_thresh=thresh)
       b. Replay stored raw masks through smoother.smooth(mask, return_iou=True)
       c. Compute pct_stable = % of frames with returned_iou >= 0.85 (skip first frame)
       d. Compute pct_failure = % of frames where returned_iou == 0.0
    6. Print a grid table sorted by pct_stable descending:
       ```
       alpha  | c_thresh | pct_stable | pct_failure
       -------|----------|------------|------------
       0.45   | 0.30     |   91.2%    |   1.8%
       ...
       ```
    7. Print: "BEST PARAMS: alpha={a}, consistency_thresh={c} => {pct_stable:.1f}% stable"
    8. If best pct_stable >= 90%: print "SEG-01 TARGET MET"
       Else: print "BEST ACHIEVED: {pct_stable:.1f}% — below 90% target. Document in SUMMARY."
    9. Validate SEG-03 constraint for the winning alpha:
       Print: "SEG-03 CHECK: alpha={a} >= 0.25 — PASS" or "FAIL — alpha too low"

    Key implementation details:
    - Collect raw masks in a Python list: raw_masks = []
    - Use cap.read() in a loop, call detector.process_frame(frame) → raw_masks.append(mask)
    - The sweep loop replays raw_masks — no GPU needed for the sweep itself
    - If len(raw_masks) < 10: print error and exit (video not readable)

    After writing, run the sweep:
    `python scripts/tune_smoother.py --video test_video_mar3_1_h264.mp4 --max-frames 500`

    Record: best alpha, best consistency_thresh, achieved pct_stable.
