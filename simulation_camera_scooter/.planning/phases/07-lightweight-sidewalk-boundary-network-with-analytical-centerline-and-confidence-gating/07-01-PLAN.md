<objective>
Build the first usable Phase 7 foundation for a lightweight sidewalk-boundary network.

This plan replaces dense-mask-only path recovery with a smaller boundary-first contract:
- export row-wise boundary supervision from existing masks,
- train a tiny network that predicts left/right boundaries and valid rows,
- decode those predictions into an analytical centerline path in metric space,
- expose confidence and slowdown outputs so the controller can degrade safely instead of guessing through ambiguous turns.
</objective>

<success_criteria>
- Boundary targets can be exported repeatably from existing JSONL mask records.
- A tiny CNN can train and evaluate offline on the boundary-record format.
- Prediction decoding returns a BEV-compatible metric path, pixel path, width estimate, confidence score, and slowdown recommendation.
- Focused tests cover extraction, dataset/model contract, and inference confidence behavior.
</success_criteria>

<notes>
- This is foundation work for the Phase 7 architecture track. It does not replace Phase 3 demo integration.
- The decoder mirrors the existing controller coordinate system: forward-x, lateral-y, and resampled polylines.
- The next plan should connect this decoder to offline video/frame evaluation before any live-control integration.
</notes>
